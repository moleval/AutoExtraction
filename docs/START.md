# Быстрый старт AutoExtraction

## Установка

1. Скопируйте папку `AutoExtraction` в удобное место, например `C:\AutoExtraction`.
2. В AutoCAD добавьте пути поддержки (меню «Сервис» > «Параметры» > «Файлы» > «Пути поиска поддержки»):
   - `C:\AutoExtraction`
   - `C:\AutoExtraction\Extraction`
   - `C:\AutoExtraction\common`
3. Убедитесь, что системная переменная `LISPSYS = 0` (для AutoCAD 2021+).

## Загрузка

Загрузите модули одним из способов:

- `(load "reload.lsp")` — загружает все модули проекта (общие, задачи, диспетчер, плагины) и выводит отчёт по каждому файлу. Повторяйте после правок кода.
- `(load "extraction.lsp")` — только диспетчер.

Команда `RELOAD` делает то же самое повторно. Отчёт `RELOAD` содержит число загруженных модулей и маркер редакции; после `git pull` сверяйте их с документацией.

## Диспетчер EXTRACTION

Команда `EXTRACTION` (или `ЭКСТРАКЦИЯ`) открывает главное окно. Порядок работы:

1. **Слои.** Отметьте слои, на которых лежат исходные данные. Если ничего не отмечено, программа просматривает все слои. Поле «Поиск» над списком сужает его по маске (`*`, `?`, `#`, `@`), подробности — [search-masks.md](search-masks.md).
2. **Групповые фильтры слоёв.** Чекбоксы **Мои**, **Фасады**, **Витражи**, **Окна** включают слои, которые входят в одноимённые групповые фильтры AutoCAD. Фильтр «Мои» — весь фильтр «Стройплэкс» со вложенными группами. Чекбокс **Анонимные блоки** работает в панели «Блоки» и в систему фильтров слоёв не входит: он оставляет в списке только анонимные блоки (имена вида `A$C…`).
3. **Блоки.** Панель «Блоки» позволяет найти блок по имени (поле «Поиск», подтверждается Enter), скопировать его (`Копия`), вставить (`Вставить`) и задать имя (`Имя`). Эти кнопки не меняют правила отчётов.
4. **Задача.** Выберите одну из задач:
   - **Фасонка** — погонаж фасонок по блокам с параметром «ДЛИНА»;
   - **Подсистема** — подсчёт элементов подсистемы по видимости блоков;
   - **Облицовка** — площади облицовочных панелей;
   - **Заполнение** — стеклопакеты, сэндвич-панели и другие блоки заполнения;
   - **Витраж** — в разработке, отчёта пока нет.
5. **Режим отчёта.** `Подробный` (DETAIL) или `Краткий` (SUMMARY).
6. **Вывод.** Отметьте нужные варианты: `.xls` (Excel), `.txt` (файл `.gal` для станка с ЧПУ), `AutoCAD` (таблица в чертеже).
7. **Раскрой.** Кнопки `Раскрой хлыста` (карта линейного раскроя) и `Раскрой листа` (карта раскроя листов) открывают отдельные диалоги с собственными настройками.
8. Нажмите `Сохранить` — отчёт сохраняется с именем по умолчанию в папке чертежа; `Сохранить как...` — с выбранным именем файла.

Кнопка `Настройки` открывает окно правил задач (маски слоёв и блоков, слой таблицы, имя выходного блока карты, припуск на раму для задачи «Заполнение»). Изменения записываются в `settings.ini`. Кнопка `?` открывает расширенную справку по окну.

## Карты раскроя

- **Раскрой хлыста** (`CUTLINE`) и **Раскрой листа** (`CUTSHEET`) строят карту из деталей исходного чертежа и вставляют её блоком. Имя выходного блока задаётся в `settings.ini` (`output.block.template`, `{DWG}` — имя чертежа).
- Если у детали есть атрибут «МАРКА», значение подписывается в углу детали на карте. Список изделий в хлыстовом отчёте выводит отдельную строку на каждую марку. Подробности — [marks-in-maps.md](marks-in-maps.md).
- Для блоков заполнения размер берётся «в свету» и увеличивается на припуск на раму (`input.frame.allowance`, по умолчанию 26 мм). Подробности — [fill-allowance.md](fill-allowance.md).
- Отчёты раскроя (XLS, CSV) сохраняются рядом с чертежом; карта раскроя вставляется в текущее пространство модели по указанной точке (`Esc` — отказаться).

## Плагины

Сторонние модули загружаются тем же RELOAD'ом последними, после модулей проекта
(секция `--- PLUGINS ---` в отчёте). Список имён — `*ae-reload-plugin-files*`
в `reload.lsp`.

Для каждого имени RELOAD ищет файл в двух местах, по приоритету:

1. **Каталоги разработки** — список `*ae-reload-plugin-dev-dirs*` в `reload.lsp`
   (сейчас `D:\PlotFrameToPDF`). Первый каталог, в котором файл найден, выигрывает;
   в логе такой плагин помечен: `Загружен: D:\PlotFrameToPDF\PlotFrameToPDF.lsp
   [разработка]`. Копия в проекте не нужна и в git не кладётся — иначе она
   расходилась бы с репозиторием плагина молча.
2. **Папка `Plugins\`** в корне проекта — для плагинов, которые приняты и
   поставляются вместе с проектом.

Плагин молча пропускается, если его нет ни в одном каталоге разработки и папки
`Plugins\` в проекте нет: ни строки «НЕ НАЙДЕН», ни влияния на итоговые счётчики.
Если папка `Plugins\` есть, а заявленного файла в ней нет — это ошибка, она
попадает в «Не найдено файлов».

Модуль в каталоге разработки проверяется так же, как код проекта:
`python tests\static_check.py` покажет его в строке `plugins-dev=N`, а `CHKALL`
в AutoCAD проверит скобки именно того файла, который грузит RELOAD.

Подключён `PlotFrameToPDF.lsp` — экспорт области, выделенной рамкой, в PDF
(`DWG To PDF.pc3`). Команды: `ЭКСВПДФ` / `EXPTPDF` — печать, `ОЧИСТПДФ` —
очистка папки вывода, `ПФПТАБЛ` — таблица форматов, `ПФПСТАТ` — настройки,
`ПФПМЕДИА` — список доступных media, `ПФПЦВЕТ` / `ПФПЧБ` — цветная или ч/б,
`ПФППАПКА` — папка вывода, `ПФПТЕМП` — открыть `%TEMP%\PlotFramePDF`. Файлы
сохраняются как `<номер>.pdf`, без суффиксов. Путь поддержки для плагинов не
нужен: RELOAD грузит их по полному пути.

Три особенности, которые стоит знать:

- После `git pull` первый прогон RELOAD может не показать секцию PLUGINS: тело
  команды исполняется в прежней редакции, а самообновление `reload.lsp`
  происходит уже внутри прогона. Второй прогон загружает плагины штатно.
- Повторный RELOAD возвращает настройки плагина к умолчаниям (модуль задаёт их
  на верхнем уровне файла), поэтому `ПФПЦВЕТ` / `ПФПЧБ` / `ПФППАПКА` действуют
  до следующего RELOAD.
- Каталоги разработки имеют приоритет: если файл лежит и в `D:\PlotFrameToPDF`,
  и в `Plugins\`, загружен будет первый, а в логе будет пометка `[разработка]`.

## Примечания

- Если ничего не выбрано в списке слоёв, задача выполняется по всем слоям чертежа (кроме случаев, когда активен групповой фильтр без слоёв — тогда задача не запускается и выводит причину).
- Excel-файл `.xls` — это XML Spreadsheet, он создаётся без Microsoft Excel. Если файл записать не удалось (чаще всего он открыт в Excel), программа сохраняет CSV с тем же базовым именем.
- Таблица AutoCAD вставляется в текущее пространство модели по указанной точке (можно отказаться, нажав Esc).
- Модуль `reload.lsp` перезагружает все LSP-файлы проекта, если вы вносили изменения в код.

## Диагностика

- Если кириллица отображается неправильно, проверьте кодировку файлов (должна быть Windows-1251).
- Если не удаётся найти `extraction.dcl`, проверьте пути поддержки.
- При ошибках выполнения смотрите командную строку AutoCAD — там выводятся сообщения.
