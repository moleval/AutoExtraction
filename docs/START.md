# Быстрый старт AutoExtraction

## Установка

1. Скопируйте папку `AutoExtraction` в удобное место, например `C:\AutoExtraction`.
2. В AutoCAD добавьте пути поддержки:
   - `C:\AutoExtraction`
   - `C:\AutoExtraction\Extraction`
   - `C:\AutoExtraction\common`
   
   (Меню: `Tools` ? `Options` ? `Files` ? `Support File Search Path`)

3. Убедитесь, что системная переменная `LISPSYS = 0` (для AutoCAD 2021+).

## Загрузка и запуск

### Первый способ: через диспетчер
1. В командной строке AutoCAD введите `(load "extraction.lsp")` или `(load "reload.lsp")`.
2. Выполните команду `EXTRACTION` (или `ЭКСТРАКЦИЯ`).
3. В появившемся окне:
   - Выберите задачу (Фасонка или Подсистема).
   - Отметьте нужные слои (если не выбрано — обрабатываются все).
   - При необходимости включите фильтры по групповым фильтрам слоёв (Фасады, Витражи, Фонари).
   - Выберите режим отчёта (Подробный / Краткий).
   - Отметьте форматы вывода (`.xls`, `.gal`, таблица AutoCAD).
   - Нажмите `Сохранить` для запуска с путём по умолчанию или `Сохранить как...` для указания имени файла.

### Второй способ: из командной строки
- Для Фасонки: `FASONKA`
- Для Подсистемы: `SUBSYSTEM`
- Для линейного раскроя: `CUTLINE`

## Примечания
- Если ничего не выбрано в списке слоёв, задача выполняется по всем слоям чертежа.
- Excel-файл создаётся с формулами; если Microsoft Excel не установлен, автоматически создаётся CSV.
- Таблица AutoCAD вставляется в текущее пространство модели по указанной точке (можно отказаться, нажав Esc).
- Модуль `reload.lsp` перезагружает все LSP-файлы проекта, если вы вносили изменения в код.

## Диагностика
- Если кириллица отображается неправильно, проверьте кодировку файлов (должна быть Windows-1251).
- Если не удаётся найти `extraction.dcl`, проверьте пути поддержки.
- При ошибках выполнения смотрите командную строку AutoCAD — там выводятся сообщения.
