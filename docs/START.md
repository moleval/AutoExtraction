# Быстрый старт AutoExtraction

## Установка

1. Скопируйте папку `AutoExtraction` в удобное место, например `C:\AutoExtraction`.
2. В AutoCAD добавьте пути поддержки:
   - `C:\AutoExtraction`
   - `C:\AutoExtraction\Extraction`
   - `C:\AutoExtraction\common`
   
   (Меню: `Tools` → `Options` → `Files` → `Support File Search Path`)

3. Убедитесь, что системная переменная `LISPSYS = 0` (для AutoCAD 2021+).

## Загрузка и запуск

### Первый способ: через диспетчер
1. В командной строке AutoCAD введите `(load "extraction.lsp")` или `(load "reload.lsp")`.
2. Выполните команду `EXTRACTION` (или `ЭКСТРАКЦИЯ`).
3. В появившемся окне:
   - Выберите задачу: Фасонка, Подсистема, Облицовка, Заполнение. Витраж пока заглушка (данные не извлекаются).
   - Отметьте нужные слои (если не выбрано — обрабатываются все).
   - При необходимости включите фильтры по групповым фильтрам слоёв: Мои, Фасады, Витражи, Окна (см. [requirements.md](requirements.md), раздел 1.1).
   - Выберите режим отчёта (Подробный / Краткий).
   - Отметьте форматы вывода: `.xls`, `.txt` (создаёт GAL-файл `.gal`), AutoCAD (таблица или карта в чертеже).
   - Нажмите `Сохранить` для запуска с путём по умолчанию или `Сохранить как...` для указания имени файла.
   - Кнопка `Поиск` открывает окно поиска по атрибутам и видимостям (раздел «Поиск по атрибутам и видимостям»).
   - Кнопка `Плагины…` открывает список плагинов (раздел «Плагины»).

### Второй способ: из командной строки
- Фасонка: `FASONKA`
- Подсистема: `SUBSYSTEM`
- Облицовка: `CLADDING`; блоки облицовки: `CLBLOCKS`
- Заполнение: `ZAPOLNENIE`
- Раскрой хлыста: `CUTLINE`; раскрой листа: `CUTSHEET`
- Панель «Блоки»: `BLOCKCOPY` (копия), `BLOCKRENAME` (переименование)
- Поиск: `SEARCHBLOCK` / `ПОИСКБЛОК` (все блоки), `SEARCHATTR` / `ПОИСКАТР` (по атрибутам), `SEARCHVIS` / `ПОИСКВИД` (по видимостям)

## Плагины

Список плагинов открывается кнопкой «Плагины…» в диспетчере `EXTRACTION`.

Сторонние модули грузятся тем же RELOAD'ом последними, после модулей проекта
(секция `--- PLUGINS ---` в отчёте). Плагинов может быть несколько; каждый из них
в отчёте получает строку `Загружен: <путь>`. Список хранится в `settings.ini`, секция
`[plugins]`: `plugin.count` и для каждого плагина `plugin.N.name` (имя файла) и
`plugin.N.path` (полный путь). Пути абсолютные и хранятся в git: на всех тестовых ПК они
одинаковые. Если на каком-то ПК путь другой, исправьте его через «Изменить путь…» и
учитывайте, что файл `settings.ini` попадёт в коммит.

Управление списком — кнопкой «Плагины…» в окне `EXTRACTION` (между «Сохранить как...» и «Закрыть»):

- «Добавить…» — выбрать файл `.lsp` в стандартном диалоге; имя берётся из имени файла;
- «Изменить путь…» — выбрать другой файл для выбранной строки;
- «Удалить» — убрать плагин из списка.

Изменения попадают в `settings.ini` при «Сохранить» в окне настроек; «Отмена» их отменяет.
`CHKALL` проверяет все плагины из реестра так же, как модули проекта.
Одно имя — одна запись: если выбран второй файл с тем же именем, путь заменяется.

Как RELOAD ищет файл плагина:

1. Путь из реестра задан и файл по нему есть — грузится этот файл.
2. Путь задан, файла нет — в логе строка `НЕ НАЙДЕН по пути <путь>`, плагин не
   загружается, в окне настроек у него статус «НЕ НАЙДЕН». Другой файл RELOAD сам не
   подставляет: путь исправляется через «Изменить путь…».
3. Путь пустой — `Plugins\<имя>` в корне проекта.

Порядок загрузки — порядок записей в реестре (порядок добавления). Повтор имени в
`settings.ini` пропускается с записью в лог. Если базовое имя `name` не совпадает с
именем файла по `path`, в логе предупреждение.

Программа не знает содержимого плагинов. Скобки и кодировка плагина проверяются по факту
ошибки: если загрузка файла завершилась ошибкой, выводится диагностика CHKPARENS. Заранее
RELOAD их не проверяет. Перекрытие имён функций: если `(defun NAME` плагина уже определена
проектом или другим плагином, в логе выводится «ВНИМАНИЕ: функция NAME уже определена», и
загрузка продолжается.

На тестовых ПК подключены: `PlotFrame.lsp` (v1.09, `D:\PlotFrameToPDF`) — печать рамок и
форматов СПДС в PDF и на принтер; файлы `MARKZ.lsp` и `MarkV.lsp` из `D:\MarkZ`. Их команды
описаны в самих плагинах, здесь они не перечисляются.

Команды `PlotFrame.lsp` (их печатает сам плагин при загрузке):

- `ЭКССПДСПДФ` (`EXPSPDSPDF`) — СПДС → один PDF (склейка);
- `ЭКСПДФ` (`EXPPDF`) — рамка → PDF по габаритам;
- `ЭКСФПА4` (`EXPFPA4`) — рамка → принтер A4 (FinePrint);
- `ЭКСФПА3` (`EXPFPA3`) — рамка → принтер A3;
- `ЭКССПДСФП` (`EXPSPDSFP`) — СПДС → принтеры A4/A3 по рамке;
- `ОЧИСТПДФ` — удалить PDF папки чертежа;
- `ПСПНАСТРОЙКИ` (`PSPSET`) — папка, принтеры, цвет, качество;
- `ПСПЭХОВКЛ` / `ПФПЭХОВКЛ` / `ФПЭХОВКЛ` — эхо ленты печати; `ЭКССПДСДИАГ` — диагностика СПДС.

Формат и ориентация берутся из рамки; настройки и цвет общие (`ПСПНАСТРОЙКИ`). Результаты
в `<вывод>\<имя чертежа>\`: СПДС — альбом `<имя>_<дата>_<время>.pdf`, рамки — `1.pdf`,
`2.pdf` и т. д. Архивные файлы плагина (`archive/`) не загружаются. Путь поддержки для
плагинов не нужен: RELOAD грузит их по полному пути из реестра.

Особенность: после `git pull` первый прогон RELOAD может не показать секцию PLUGINS: тело
команды исполняется в прежней редакции, а самообновление `reload.lsp` происходит уже внутри
прогона. Второй прогон загружает плагины штатно.

## Поиск по атрибутам и видимостям

Окно открывается кнопкой «Поиск» в диспетчере или командами `SEARCHBLOCK` / `SEARCHATTR` / `SEARCHVIS`
(`ПОИСКБЛОК` / `ПОИСКАТР` / `ПОИСКВИД`); режим переключается радиокнопкой в окне. Отметьте блоки слева и/или пункты справа, нажмите «Выбрать» (в текущей области) или «Выбрать подобное» (по всему чертежу по образцу и выбранному блоку, видимости или атрибуту) —
подходящие вставки выделятся в чертеже. «Сбросить выбор» снимает выбор; «Закрыть» или Esc
закрывают окно. Полное описание — [requirements.md](requirements.md) §15.

## Примечания
- Если ничего не выбрано в списке слоёв, задача выполняется по всем слоям чертежа.
- Файл `.xls` создаётся без Microsoft Excel (XML Spreadsheet, с формулами). CSV создаётся автоматически, только если записать XLS не удалось (например, файл открыт в Excel).
- Таблица AutoCAD вставляется в текущее пространство модели по указанной точке (можно отказаться, нажав Esc).
- Модуль `reload.lsp` перезагружает все LSP-файлы проекта, если вы вносили изменения в код.

## Диагностика
- Если кириллица отображается неправильно, проверьте кодировку файлов (должна быть Windows-1251).
- Если не удаётся найти `extraction.dcl`, проверьте пути поддержки.
- При ошибках выполнения смотрите командную строку AutoCAD — там выводятся сообщения.
