## Шаг 1. Панель «Блоки»: внешний вид

```
EXTRACTION
```

В диалоге на панели **БЛОКИ**:

- [ ] поле поиска **без надписи «Поиск:»**, тянется на всю ширину панели (как список);
- [ ] в пустом поле виден текст **«Поиск (по Enter):»**;
- [ ] кнопки в ряд: **Копия | Вставить | Имя** (третья раньше была «Переименовать»).

Закройте диалог (Отмена/крестик) — ошибок быть не должно.

## Шаг 2. Поиск с подсказкой

Откройте `EXTRACTION` снова:

1. Не трогая поле — список показывает **все** блоки (подсказка не считается запросом).
2. Щёлкните в поле и допечатайте любой символ **после** подсказки (не стирая её) → Enter →
   подсказка срезается, в поле остаётся только ваш запрос, список фильтруется.
3. Сотрите всё содержимое поля → Enter → в поле снова подсказка, список полный.
4. Выделите любой блок в списке, нажмите **Копия** → как раньше: диалог закрывается,
   запрашивается точка, копия вставляется. (Регресс — поведение Копии не изменилось.)

- [ ] пп. 1–4

*Примечание:* если впечатать запрос **перед** подсказкой (курсор в начало) — тоже сработает:
подсказка срезается, остаётся ваш текст.

## Шаг 3. Кнопка «Вставить»

1. `EXTRACTION` → выделите в списке простой блок → **Вставить**.
2. Диалог закрывается, в командной строке: `Укажите точку вставки блока "<имя>":`
3. Щёлкните точку в модели → блок вставлен (масштаб 1, поворот 0), сообщение:
   `Вставлен блок: "<имя>"`
4. Одно `U` — вставка уходит целиком (одна группа UNDO), `REDO` возвращает.
5. Снова `EXTRACTION` → ничего не выделяя в списке → **Вставить** →
   `Блок для вставки не выбран.`
6. Снова: выделите блок → **Вставить** → на запросе точки нажмите **ESC** →
   `Вставка отменена.`, ошибок нет.

- [ ] пп. 1–6
