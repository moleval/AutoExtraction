# Спецификация задачи «Заполнение» (ZAPOLNENIE)

**Модуль:** `Extraction/zapolnenie.lsp`  
**Команды:** `ZAPOLNENIE`, `ЗАПОЛНЕНИЕ`  
**Назначение:** Образец для задачи «Облицовка»

---

## 1. Общие сведения

Задача «Заполнение» извлекает данные о заполнении проёмов из динамических блоков на выбранных слоях.

**Типы блоков:** стеклопакеты, сэндвич-панели, глухие панели, витражное стекло.

**Основная величина:** ПЛОЩАДЬ (м?), количество (шт.).

**Слои по умолчанию:** не заданы жёстко. Пользователь указывает слои в командной строке или выбирает в диспетчере. Пустой ввод = все слои.

---

## 2. Логика извлечения данных

### 2.1 Выбор блоков
- Используются **выделенные объекты** (как в Фасонке и Подсистеме)
- Функция `su-select-inserts` из `common/select-utils.lsp`
- Учитывает предварительный выбор `*extraction-preselected-set*` и указанные слои
- Пустой ввод слоёв = все слои

### 2.2 Извлекаемые данные из каждого блока

| Поле | Источник | Метод |
|---|---|---|
| **ТИП** | Видимость, если есть; иначе — `EffectiveName` | `su-get-visibility` ? fallback на `su-get-effective-name` |
| ***высота*** | Динамическое свойство | Приоритет поиска: `ВЫСОТА В СВЕТУ` ? `ВЫСОТА` |
| ***ширина*** | Динамическое свойство | Приоритет поиска: `ШИРИНА В СВЕТУ` ? `ШИРИНА` ? `ДЛИНА` |

**Важно:** отсутствие видимости **не означает ошибку элемента**. Блоки без видимости обрабатываются с именем блока как наименованием.

### 2.3 Поиск свойств (двухступенчатый)

Для каждого ключевого слова:
1. **Сначала точное совпадение** имени свойства
2. **Если не найдено — поиск по подстроке**

Это защищает от ложных срабатываний (например, «Высота в свету 2», «Высота рамки»).

### 2.4 Приоритет поиска свойств

```
Высота:  ВЫСОТА В СВЕТУ ? ВЫСОТА
Ширина:  ШИРИНА В СВЕТУ ? ШИРИНА ? ДЛИНА
```

Свойства `Ширина` и `Длина` идентичны по смыслу (горизонтальный размер).

### 2.5 Вычисление производных величин

```
ВЫСОТА  = округлить(*высота* + 26)   мм
ШИРИНА  = округлить(*ширина* + 26)   мм
ПЛОЩАДЬ = ВЫСОТА ? ШИРИНА / 1 000 000   м?
```

- **Константа 26 мм** — припуск на рамку/профиль
- **Округление размеров:** `fix` (до целых мм)
- **Нулевой размер:** пропуск с раздельным счётчиком причин

### 2.6 Обработка блоков без размеров
- Если *высота* или *ширина* не найдены или равны нулю ? блок пропускается
- Ведётся **раздельный счёт**: без высоты / без ширины
- Счётчики выводятся в итоговом сообщении

## 4. Структура данных

### 4.1 Запись в `zapolnenie-aggregate` (внутренняя)
```
(key name h w count)
  1    2   3 4   5
```
Где `key = UPPERCASE(name)|h|w` — ключ агрегации.

**Важно:** при увеличении количества использовать `(car (cddddr found))` — 5-й элемент. Использование `(cadddr found)` (4-й элемент = ширина) — **критичный баг**.

### 4.2 Запись DETAIL (возвращаемая)
```
(тип высота-мм ширина-мм количество)
Пример: ("Сэндвич" 776 776 3)
```

### 4.3 Запись в `zapolnenie-build-summary` (внутренняя)
```
(key name count area)
  1    2    3    4
```
Где `key = UPPERCASE(name)`.

**Важно:** при увеличении количества и площади обновлять оба значения:
```
(список key (cadr found) (+ (caddr found) cnt) (+ (cadddr found) area))
```

### 4.4 Запись SUMMARY (возвращаемая)
```
(тип количество площадь-м2)
Пример: ("Сэндвич" 5 3.35)
```

## 5. Режимы отчёта

### 5.1 DETAIL (подробный)
Каждая уникальная комбинация **(ТИП, ВЫСОТА, ШИРИНА)** — отдельная строка.

### 5.2 SUMMARY (краткий)
Агрегация по **ТИПУ** (видимости). Строится из DETAIL одним проходом.

## 7. Экспорт XLS / CSV

### 7.1 XLS DETAIL
**Колонки:** `№ | Тип | Высота, мм | Ширина, мм | Кол-во, шт. | Площадь, м2`
- Ширина столбца «Тип»: **125**
- Формат площади: `0.##` (подавление нулевых знаков)
- Группировка по типам с подитогами групп
- Формулы площади в строках данных: `=RC[-3]*RC[-2]*RC[-1]/1000000`
- Формулы подитогов групп: `=SUM(R{start}C5:R{end}C5)`
- Общий итог суммирует только строки подитогов групп

### 7.2 XLS SUMMARY
**Колонки:** `№ | Тип | Кол-во, шт. | Площадь, м2`
- Ширина столбца «Тип»: **125**
- Формат площади: `0.##`
- Итоговая строка с формулами `=SUM(...)`

### 7.3 CSV
**Разделитель:** `;` (единообразно с Подсистемой)  
**Десятичный разделитель:** `,` (запятая)  
**Площадь:** в кавычках, с подавлением нулей: `"3,35"`  
**Текст:** в кавычках при наличии спецсимволов

### 7.4 Переключение на CSV
При недоступности XLS (файл открыт в Excel) — автоматическое создание CSV. Механизм: функции экспорта возвращают `nil` при недоступности файла, основная функция переключается на CSV.

## 13. Найденные баги и их исправления

### 13.1 КРИТИЧНЫЙ: неверное количество при агрегации
**Симптом:** повторяющиеся панели давали кол-во = ширина+1 (627 шт. вместо 2).  
**Причина:** `(1+ (cadddr found))` увеличивал 4-й элемент (ширину) вместо 5-го (количества).  
**Исправление:** `(1+ (car (cddddr found)))`.  
**Урок:** всегда комментировать структуру записи списков.

### 13.2 Сортировка DETAIL не шла по высоте/ширине
**Симптом:** размеры одного типа выводились лексикографически (1226 раньше 526).  
**Причина:** `zapolnenie-sort-less` читал `car/cadr/caddr` = ключ/имя/высоту вместо имени/высоты/ширины.  
**Исправление:** использовать `cadr/caddr/cadddr`.  
**Урок:** проверять индексы элементов списков при изменении структуры записи.

### 13.3 Пробел после запятой при вводе слоёв
**Симптом:** `"Заполнение, Стекло"` давало имя `" СТЕКЛО"`, выборка шла только по первому слою.  
**Причина:** `split-string` не обрезает пробелы.  
**Исправление:** `vl-string-trim` в `c:zapolnenie`.  
**Урок:** технический долг по `split-string` зафиксирован в `docs/tech-debt.md` (TD-001).

## 14. Рекомендации для адаптации под «Облицовку»

### 14.1 Что переиспользуется
- Функция извлечения размеров со списком ключевых слов
- Логика «видимость или имя»
- Агрегация по (тип, высота, ширина)
- Экспорт в `common/`
- Механизм переключения на CSV
- Подсчёт пропусков

### 14.2 Что меняется для Облицовки
| Параметр | Заполнение | Облицовка (предположительно) |
|---|---|---|
| Извлекаемые свойства | Высота/Ширина | Другие (например, тип панели, толщина) |
| Формулы | Площадь | Площадь или объём |
| Константы | Припуск 26 мм | Другие припуски или без них |
| Формат GAL | `№_Тип/высота/ширина/количество/` | Другой формат |
| Размер листа | 3210x2250 | Другой |
| Слои по умолчанию | Не заданы | Не заданы |

### 14.3 Чего избегать (уроки Заполнения)
1. **Не использовать `fboundp`** — её нет в AutoLISP. Использовать `vl-catch-all-apply`.
2. **Комментировать структуру записей списков** — чтобы избежать ошибок с индексами.
3. **Проверять индексы элементов** при изменении структуры записи.
4. **Округлять площади ДО суммирования** — чтобы не терялась 0,01 в подитогах.
5. **Использовать латинскую `x`** в размере листа для GAL.
6. **Не обобщать таблицы преждевременно** — конкретная реализация для каждой задачи.
