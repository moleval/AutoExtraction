# Задача «Заполнение» (ZAPOLNENIE) — Техническое задание

## 1. Общие сведения

**Модуль:** `Extraction/zapolnenie.lsp`  
**Команды:** `ZAPOLNENIE`, `ЗАПОЛНЕНИЕ`  
**Интеграция:** через диспетчер `EXTRACTION` / `ЭКСТРАКЦИЯ`  
**Тип задачи:** извлечение данных о заполнении проёмов (стеклопакеты, сэндвич-панели, глухие панели, витражное стекло)

---

## 2. Логика извлечения данных

### 2.1 Выбор блоков
- Используются **выделенные объекты** (как в Фасонке и Подсистеме)
- Слои задаются в диспетчере или в командной строке
- Пустой ввод слоёв = все слои
- Используется `su-select-inserts` из `common/select-utils.lsp`

### 2.2 Извлекаемые данные из каждого блока

| Поле | Источник | Метод |
|---|---|---|
| **ТИП** | Состояние видимости динамического блока | `su-get-visibility` (если пусто — `su-get-effective-name`) |
| ***высота*** | Динамическое свойство, имя содержит «высота» | Поиск подстроки без учёта регистра |
| ***ширина*** | Динамическое свойство, имя содержит «ширина» | Поиск подстроки без учёта регистра |

**Поиск свойств:** имя свойства приводится к верхнему регистру, ищется подстрока `ВЫСОТА` или `ШИРИНА`. Регистр символов `*` не учитывается (считаются любыми символами).

### 2.3 Вычисление производных величин
ВЫСОТА = округлить(высота + 26) мм
ШИРИНА = округлить(ширина + 26) мм
ПЛОЩАДЬ = ВЫСОТА ? ШИРИНА / 1 000 000 м?

- **Константа 26 мм** — припуск на рамку/профиль, выносится в заголовок модуля как `*ZAPOLNENIE-FRAME-ALLOWANCE*`
- **Округление до мм** — отбрасывание дробной части (`fix`)
- Площадь округляется до 2 знаков после запятой при выводе

### 2.4 Обработка блоков без размеров
- Если *высота* или *ширина* не найдены или не являются числом ? **блок пропускается**
- Ведётся счётчик пропущенных блоков для итогового сообщения

### 2.5 Агрегация
- Объединить блоки с одинаковыми **(ТИП, ВЫСОТА, ШИРИНА)** в одну запись
- Суммировать количество
- Высота и ширина округляются до мм **до** агрегации

### 2.6 Сортировка
1. По ТИПУ (алфавит, без учёта регистра)
2. По ВЫСОТЕ (возрастание)
3. По ШИРИНЕ (возрастание)

## 3. Структура данных

### 3.1 Запись DETAIL

(тип высота-мм ширина-мм количество)
;; Пример: ("Стеклопакет" 1226 826 5)
(/ (* высота-мм ширина-мм количество) 1000000.0)

### 3.2 Запись SUMMARY
(тип количество площадь-м2)
;; Пример: ("Стеклопакет" 8 9.77)

4. Режимы отчёта
4.1 DETAIL (подробный)
Каждая уникальная комбинация (ТИП, ВЫСОТА, ШИРИНА) — отдельная строка.
4.2 SUMMARY (краткий)
Агрегация по ТИПУ (видимости).

7. Экспорт XLS / CSV
7.1 DETAIL
Колонки: № | Тип | Высота, мм | Ширина, мм | Кол-во, шт. | Площадь, м?
7.2 SUMMARY
Колонки: № | Тип | Кол-во, шт. | Площадь, м?
7.3 Формат площади
Две цифры после запятой: 0,00
В CSV — десятичная запятая: 5,07
7.4 Разделитель в CSV
Разделитель колонок: , (запятая)
Десятичный разделитель: , (запятая)
Значения площади заключаются в кавычки для корректного парсинга: 1,Стеклопакет,1226,826,5,"5,07"

8.2 Формат строки панели

Где:

ширина — ширина в мм (с припуском 26 мм, округлённая)

Размер листа=3210?2250 — размер листа для раскроя

пропущено — количество блоков без высоты/ширины
общая площадь — суммарная площадь всех панелей в м?
13. Обработка ошибок
Стандартный *error* handler с проверкой *BREAK*,*CANCEL*,*QUIT*,*EXIT*
Если блоки не найдены: "\nБлоки заполнения не найдены."
Если нет данных после агрегации: "\nНет данных для отчёта."
Если не удалось создать XLS: автоматический fallback на CSV
14. Совместимость
AutoCAD 2016 и 2023
Кодировка файлов: Windows-1251 (ANSI)
Использует общие утилиты из common/:
select-utils.lsp — выборка блоков, извлечение свойств
excel-utils.lsp — экспорт XLS/CSV
table-utils.lsp — таблицы AutoCAD (если будет расширена)

16. Примечания для реализации
Переиспользование логики подсистемы: функция получения имени элемента (видимость) может быть заимствована из subsystem.lsp
Единообразие с другими задачами: структура zapolnenie-main должна соответствовать fasonka-main и subsystem-main
Проверка зависимостей: в c:zapolnenie добавить проверку наличия функций su-*, eu-*, tx-* с сообщением о запуске RELOAD
Округление площади: при выводе использовать (rtos area 2 2) для двух знаков после запятой
Форматирование площади в CSV: заменять точку на запятую через (vl-string-translate "." "," (rtos area 2 2))

## Как использовать этот промт

1. **Сохраните** в репозиторий как `docs/zapolnenie-spec.md` или аналогичный путь
2. **Используйте** как образец для задачи «Облицовка» — структура спецификации одинакова, меняются только:
   - Извлекаемые свойства (у облицовки могут быть другие)
   - Формулы вычисления
   - Формат GAL
   - Структура таблиц

3. **Адаптируйте** для «Облицовки»:
   - Замените «Заполнение» на «Облицовка»
   - Укажите специфичные свойства облицовки (например, тип панели, толщина, цвет)
   - Скорректируйте формулы площади/объёма
   - Уточните формат GAL для облицовки

---

Если хотите, могу сразу подготовить аналогичный промт для «Облицовки» на основе этой структуры — просто пришлите специфику извлекаемых данных для этой задачи.
