# Функциональные требования

## 1. Диспетчер задач
- Открывается командой `TASKDISPATCHER` или `TASKS`.
- Окно содержит:
  - Три независимых чекбокса для фильтров слоёв: **Фасады**, **Витражи**, **Фонарь 3D**.
  - Список слоёв с множественным выбором (сортировка по алфавиту, без дубликатов).
  - Список блоков (заглушка, не используется).
  - Радиокнопки режима отчёта: **Подробный** и **Краткий**.
  - Чекбоксы вывода: `.xls`, `.gal`, `AutoCAD`.
  - Радиокнопки выбора задачи (активна только «Фасонка», остальные отключены).
  - Кнопки `Сохранить`, `Сохранить как...`, `Закрыть`, `?`.
- При включении любого фильтра слоёв список обновляется, отображая объединение слоёв выбранных групповых фильтров. Дубликаты исключаются.
- Если ни один фильтр не выбран, отображаются все слои.
- Если ни один слой не выбран, задача выполняется по всем слоям.
- Кнопка `Сохранить` запускает задачу с путём по умолчанию (`<папка чертежа>\<имя чертежа>_FASONKA`).
- Кнопка `Сохранить как...` открывает диалог выбора файла, затем запускает задачу с выбранным базовым именем.

## 2. Задача «Фасонка»
- Обрабатывает вхождения динамических блоков (`INSERT`).
- Наименование формируется из `EffectiveName`, удаляется префикс «Железо », первая буква остатка становится заглавной.
- Длина извлекается из динамического свойства, имя которого содержит «ДЛИНА» (без учёта регистра).
- Блоки без длины игнорируются.
- Агрегация:
  - **DETAIL**: группировка по «имя + длина», вычисление количества и погонажа (длина × кол-во / 1000).
  - **SUMMARY**: группировка по имени, суммирование количества и погонажа.
- Выводы:
  - Таблица AutoCAD (если включено): статические значения, без формул.
  - Excel (если включено): формулы `=C*D/1000` и `=SUM(...)`.
  - TXT (если включено): простой текст с разделителем `;`.

## 3. Экспорт в Excel
- Если Microsoft Excel доступен через COM, создаётся файл `.xls` с формулами.
- Если Excel недоступен, создаётся CSV-файл с теми же данными (без формул).

## 4. Обработка ошибок
- Отсутствие блоков → сообщение «Блоки со свойством Длина не найдены».
- Ошибка при создании таблицы AutoCAD не должна прерывать экспорт в файлы.
- Отказ от точки вставки таблицы (Esc) → таблица не создаётся, но файлы экспортируются.

## 5. Производительность
- Создание таблицы AutoCAD с точным количеством строк (без удаления лишних).
- Отключение `CMDECHO` и `REGENMODE` на время генерации.
