# Приёмка: фильтры слоёв по групповым фильтрам AutoCAD (2026-10-07)

Живой прогон в AutoCAD, 13 пунктов. Чертеж — рабочий профиль (или любой с групповыми
фильтрами вида: Все -> Стройплэкс -> Витражи / Окна / Отключенные / Фасад - *).

Подготовка: `RELOAD` (или `(load "…/reload.lsp")`) — модули должны загрузиться без
ошибок; `common/layer-utils.lsp` печатает «ред. 2», `extraction.lsp` — «ред. 3».

1. Окно диспетчера `Extraction`: в строке фильтров ровно четыре чекбокса —
   «Мои», «Фасады», «Витражи», «Окна»; «Анонимные блоки» остался отдельным.
2. Первый запуск: все четыре фильтра выключены, в списке слоёв — все слои чертежа,
   строка-подсказка в обычном виде.
3. Включить «Фасады»: в списке — слои фасадных групповых фильтров (Фасад - *),
   в подсказке «Фильтр Фасады: слоев N»; снять галочку — список возвращается ко всем слоям.
4. Включить «Витражи»: помимо «Витраж*» попадает группа «Фонарь 3D» (Фонар*).
   Включить «Окна»: только Окн*.
5. Включить «Мои»: слои «Стройплэкс» (включая вложенные на любом уровне) вместе с
   «Отключенные» и тематикой Фасад*/Витраж*/Фонар*/Окн*; дублей в списке нет.
   На профиле-примере счётчик подсказки совпадает с ожиданием (83 слоя).
6. КРИТИЧЕСКОЕ УСЛОВИЕ: слой, входящий ТОЛЬКО в группу «Отключенные», виден в списке
   при включённом «Мои» и НЕ виден при «Фасады», «Витражи», «Окна».
7. Включить «Фасады» и «Окна» одновременно: список — объединение по «или», без дублей.
8. Ручной выбор важнее фильтра: выбрать вручную 2-3 слоя, затем включить фильтр,
   который их содержит — выбор сохраняется; включить фильтр, который их не содержит —
   исчезнувшие слои снимаются, оставшиеся видимые сохраняются.
9. Запустить любую задачу (например, FASONKA) при активном фильтре и выбранных вручную
   слоях: задача работает по РУЧНОМУ выбору (слои фильтра не подменяют его).
10. Запустить задачу при активном фильтре без выбранных вручную слоёв: задача работает
    по слоям фильтра (в модуле печатается источник слоёв).
11. Пустой фильтр: строка состояния окна показывает причину коротким текстом
    (полная строка не должна обрезаться по ширине окна):
    - в чертеже нет ни одного группового фильтра — «Групповой фильтр отсутствует»,
      в командной строке `[EXTRACTION][LAYER-UTILS] Групповой фильтр отсутствует в чертеже.`;
    - фильтры есть, а слоёв по ним нет — «Нет слоев по фильтру: <фильтры>»,
      в командной строке `[EXTRACTION][LAYER-UTILS] Групповые фильтры по маскам не найдены: <фильтры>.`
    При запуске задачи — alert с той же причиной; задача НЕ запускается, окно остаётся
    открытым, молчаливой подмены всеми слоями чертежа нет.
12. CUTLINE и CUTSHEET при активном фильтре: печатается подпись источника слоёв
    «по фильтру: Мои» (для нескольких галочек — «по фильтрам: Фасады, Окна»);
    фильтрация выполняется по слоям фильтра.
13. Перезапуск окна: галочки восстанавливаются, как были (запоминаются между открытиями
    окна); снятие всех галочек возвращает все слои чертежа; чекбокс «Анонимные блоки»
    на список слоёв не влияет. Дополнительно: `LAYERFILTERTEST` — итог без FAIL
    (проверяет и тексты подсказок, включая «Групповой фильтр отсутствует»).


## Поиск слоя в панели «Слои» (ред. 4)

Правка UI по согласованию 2026-10-08. Поле поиска слоя — на уровне поля поиска
блоков; кнопки «Выбрать все» / «Снять выделение» — ниже строки состояния
фильтров, на уровне кнопок блоков (Копия / Вставить / Имя).

Принятые решения:
- при смене запроса выделение сбрасывается (как у поиска блока);
- кнопки действуют на НАЙДЕННЫЕ (видимые) слои;
- высота списка слоёв 14 -> 13, чтобы уровни кнопок совпали точно;
- подсказка в пустом поле — «Поиск (по Enter):», буквально как у блоков.

Проверить в живом прогоне:

1. Раскладка. Поле поиска слоя и поле поиска блока — на одной высоте.
   Кнопки «Выбрать все» / «Снять выделение» — на одной высоте с «Копия /
   Вставить / Имя». Размер окна не изменился.
2. Пустой поиск = прежнее поведение. Список слоёв полный, строка состояния
   прежняя («Если слои не выбраны — поиск по всем слоям» или «Фильтр ...»).
3. Поиск подстроки. Ввести «витр» + Enter: остаются только слои, содержащие
   «витр» в любом регистре. Строка состояния: «Найдено слоев: N из M».
4. Маска. Ввести «Фасад*» + Enter: только начинающиеся с «Фасад». Маски
   ? # @ работают так же, как в поиске блока.
5. Композиция с фильтром. Включить «Мои», затем ввести запрос: поиск сужает
   список фильтра и НЕ добавляет слои вне фильтра. Строка состояния:
   «Фильтр Мои: M | найдено N».
6. Сброс выбора. Выбрать несколько слоёв, ввести запрос — выделение снято.
7. Кнопки по найденному. После поиска «Выбрать все» выделяет ровно найденные
   слои; «Снять выделение» снимает их.
8. Очистка поиска. Стереть текст и нажать Enter: возвращается подсказка
   «Поиск (по Enter):», список и строка состояния — как в п. 2.
9. Нет группового фильтра. Включить фильтр, которого нет в чертеже: строка
   состояния по-прежнему «Групповой фильтр отсутствует», поиск её не затирает.
10. Запуск задачи. Слои не выбраны при активном поиске -> задача идёт по всем
    слоям (правило не изменилось: поиск — это помощник выбора, а не фильтр
    задачи).


## Раздел «Выбранные слои» в окне раскроя листа (CUTSHEET ред. 26)

показывает слои, выбор по-прежнему делает диспетчер. Размещён под блоком
«Тип динамического блока».

Проверить в живом прогоне:

1. Размещение. В окне «Раскрой листа» под блоком «Тип динамического блока»
   появился блок «Выбранные слои» со списком на 4 строки шириной как у
   выпадающего списка типов.
2. Ручной выбор. Выбрать в диспетчере 2-3 слоя -> РАСКРОЙ ЛИСТА: в списке
   перечислены именно эти слои.
3. Слои не выбраны. Ничего не выбирать -> в списке одна строка «Все слои».
4. Групповой фильтр. Включить «Мои» (слои не выбирать) -> в списке одна
   строка «по фильтру: Мои (за исключением слоя 0)»; при нескольких фильтрах
   «по фильтрам: Фасады, Окна (за исключением слоя 0)».
5. Сверка с хлыстом. Открыть «Раскрой хлыстов» при том же выборе — текст в

6. Регресс. Раскрой запускается как раньше: список информационный, на состав
   деталей и на результат не влияет.


## Счётчик в заголовке «Выбранные слои» (CUTSHEET ред. 27, CUTLINE ред. 18)

Заголовок рамки в DCL статичен: у кластера (boxed_column) нет ключа, set_tile
на него не действует. Поэтому перед открытием окна файл диалога копируется
во временный с подменённой строкой label, окно грузится из копии, копия
удаляется после закрытия. Если копию сделать не удалось, грузится исходный
файл и заголовок остаётся обычным — окно в любом случае открывается.

Проверить в живом прогоне (ОБА окна: раскрой листа и раскрой хлыстов):

1. Ручной выбор. Выбрать 3 слоя -> заголовок «Выбранные слои (3 слоя)».
2. Склонение. 1 слой -> «(1 слой)», 2-4 -> «(2 слоя)», 5 и больше ->
   «(5 слоев)», 11-14 -> «(11 слоев)», 21 -> «(21 слой)», 31 -> «(31 слой)».
3. Групповой фильтр. Включить «Витражи» -> «Выбранные слои (Фильтр Витражи:
   31 слой)». Несколько фильтров -> «Выбранные слои (Фильтры Фасады, Окна:
   N слоев)».
4. Слои не выбраны -> «Выбранные слои (все слои)».
5. Содержимое списка внутри рамки не изменилось (см. предыдущий раздел).
6. Оба окна показывают одинаковый заголовок при одном и том же выборе.
7. Временные файлы. Открыть и закрыть каждое окно по 3 раза (в том числе
   по «Отмена»), затем проверить %TEMP%: файлов ae_dcl*.dcl не остаётся.
8. Регресс. Раскрой запускается и считает как раньше.

## Выравнивание ряда фильтров (ред. 6)

«Мои», «Фасады», «Витражи», «Окна» — вплотную друг к другу у левого края;
«Анонимные блоки» — у правого. Сделано тем же приёмом, что в шапке окна:
гибкий spacer (fixed_width = false) между левой группой и правым флажком.
С внешнего ряда снят alignment = left, иначе ряд сжимается по содержимому
и растягивать отступ нечему.

Проверить в живом прогоне:

1. Четыре фильтра стоят слева вплотную, без растяжки по ширине окна.
2. «Анонимные блоки» прижаты к правому краю, на одной строке с остальными.
3. При изменении ширины окна (если оно тянется) правый флажок остаётся
   у правого края.
4. Регресс: все пять флажков читаются и переключаются как раньше,
   список слоёв перестраивается по групповым фильтрам.


## Ряд фильтров по колонкам панелей (ред. 7)

Заменяет решение ред. 6 (прижим вправо гибким отступом). Ряд фильтров теперь
повторяет геометрию ряда «Слои | Блоки»: колонка 40 + отступ 2 + колонка 40.
Все четыре ряда окна стали одной сеткой 40 + 2 + 40.

- «Мои», «Фасады», «Витражи», «Окна» — в левой колонке, вплотную друг к другу,
  над панелью «Слои» (списком слоёв и полем его поиска).
- «Анонимные блоки» — в правой колонке, над панелью «Блоки» (списком блоков
  и полем его поиска).

Проверить в живом прогоне:

1. Флажок «Мои» стоит по одной вертикали со списком слоёв и полем поиска слоя.
2. Флажок «Анонимные блоки» стоит по одной вертикали со списком блоков и
   полем поиска блока.
3. Четыре левых флажка идут вплотную, без растяжки по ширине колонки.
4. Регресс: все пять флажков переключаются, список слоёв перестраивается по
   групповым фильтрам.

Если флажок окажется сдвинут на символ влево относительно списка — это рамка
boxed_column: её содержимое утоплено внутрь рамки на ширину бордюра.
Лечится отступом spacer на доли символа в начале колонки.


## Выравнивание геометрии окна по вертикалям (ред. 8)

Причина «расползания» была в том, что внутри панелей стояли ТРИ разные
жёстко заданные ширины: поле поиска 38, список 40, кнопки 19+19 и 12+13+13.
Совпасть по краям они не могли в принципе — DCL добавляет к каждому типу
тайла свои поля.

Что сделано (выравнивание по построению, без подбора чисел):

1. Внутри панелей «Слои» и «Блоки» жёсткие ширины убраны совсем. Каждый
   элемент заполняет ширину панели, поэтому левые и правые края поля поиска,
   списка, поля имени и ряда кнопок совпадают автоматически. Кнопки делят
   ширину панели поровну: «Выбрать все» + «Снять выделение» пополам,
   «Копия» + «Вставить» + «Имя» по трети.
2. Ряды фильтров положены в boxed_column с ПУСТЫМ заголовком (label = "").
   Это тот же контейнер, что и панели, значит отступ от рамки такой же —
   чекбоксы встают ровно над полями поиска. Побочный эффект: вокруг групп
   фильтров видна тонкая рамка без надписи.

Проверить в живом прогоне (по вертикальным линиям):

1. Левый край «Мои» совпадает с левым краем поля поиска слоёв и списка слоёв.
2. Правый край «Снять выделение» совпадает с правым краем поля поиска слоёв.
3. Левый край «Анонимные блоки» совпадает с левым краем поля поиска блоков.
4. Правый край «Имя» совпадает с правым краем поля поиска блоков.
5. Дополнительно: правый край списка совпадает с правым краем поля поиска
   в обеих панелях (раньше список был уже).
6. Регресс: поиск, выбор слоёв, кнопки блоков и фильтры работают как раньше.

Если тонкая рамка вокруг фильтров не нравится — варианта два: дать рамкам
заголовки («Фильтры слоёв» / «Фильтр блоков») или вернуть обычную колонку
и подобрать отступ spacer вручную по живому окну.


## Ширина колонок и горизонт кнопок (ред. 9)

1. Все ВОСЕМЬ рамок окна расширены синхронно, 40 -> 45 символов: две рамки
   фильтров, «Слои», «Блоки», «Задачи», «Слои подсистемы», «Режим отчета»,
   «Вывод». Зазор между колонками прежний (2 символа), поэтому он остаётся
   ровно по центру окна. Расширять рамки по отдельности нельзя — сетка
   50 + 2 + 50 держится на том, что все восемь чисел одинаковы.
2. Ряд кнопок «Выбрать все / Снять выделение» опущен на отступ 0,25 строки,
   чтобы встать на один горизонт с «Копия / Вставить / Имя». Причина
   расхождения: в панели «Слои» третьим элементом идёт текст статуса, а в
   панели «Блоки» — поле ввода имени; поле выше текста на высоту своей рамки.

Проверить в живом прогоне:

1. Панели «Слои» и «Блоки» стали заметно шире, зазор между ними сохранился
   по центру окна.
2. Все рамки окна одной ширины и выровнены по вертикали: левые края рамок
   фильтров, «Слои», «Задачи», «Режим отчета» на одной линии; то же справа
   для «Блоки», «Слои подсистемы», «Вывод».
3. Кнопки «Выбрать все» и «Снять выделение» стоят ровно на одном горизонте
   с «Копия», «Вставить», «Имя».
4. Вертикали ред. 8 не разъехались: левый край «Мои» = левый край поля
   поиска слоёв; правый край «Снять выделение» = правый край поля поиска.
5. Окно целиком помещается на экране.
6. Регресс: поиск, выбор слоёв, кнопки блоков, фильтры работают как раньше.

Если кнопки всё ещё разойдутся по горизонту на пару пикселей — крутится
один параметр: высота spacer перед рядом кнопок в панели «Слои» (сейчас
0.25). Если окно окажется слишком широким — уменьшить все восемь width
одним числом.
