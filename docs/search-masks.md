# Маски поиска в полях «Поиск»

Поля «Поиск» в панелях «Слои» и «Блоки» главного окна используют механизм
`wcmatch` — тот же, которым пользуется сам AutoCAD в фильтрах слоёв.
Отбор срабатывает по нажатию Enter; пустое поле показывает весь список.

## Два режима запроса

| в запросе | что происходит | пример |
|---|---|---|
| нет знаков `* ? # @` | запрос оборачивается в `*запрос*`, ищется ВХОЖДЕНИЕ | `подс` -> `*подс*` -> три слоя «Подсистема…» |
| есть хотя бы один | запрос берётся КАК ЕСТЬ и должен описывать имя ЦЕЛИКОМ | `Подсистема*` -> те же три слоя |

Это главная ловушка: как только появляется маска, автоматическая обёртка
отключается.

    RAL7024     ->  маска *RAL7024*   ->  2 слоя    обёртка добавлена сама
    RAL70#4     ->  маска RAL70#4     ->  0 слоёв   имя длиннее маски
    *RAL70#4*   ->  маска *RAL70#4*   ->  2 слоя    звёздочки дописаны руками

## Символы

| символ | значение | пример | найдёт |
|---|---|---|---|
| `*` | любое число любых символов, в том числе ноль | `Подсистема*` | Подсистема, Подсистема алюминиевая, Подсистема оцинкованная |
| `?` | ровно один любой символ | `О?и` | Оси |
| `#` | ровно одна цифра | `Кр4530#-#` | Кр45302-1, Кр45303-2 |
| `@` | ровно одна буква | `@@@` | DIM, Оси |

Дополнительно работает остальной синтаксис `wcmatch`:

- `,` — ИЛИ: `Кр45302*,Кр45303*` найдёт обе серии блоков;
- `~` в начале — КРОМЕ: `~*невидимый*` покажет блоки без слова «невидимый».

Тильду обязательно писать со звёздочками. Запрос `~Подсистема` знаков маски
не содержит, поэтому превратится в `*~Подсистема*`, где тильда станет
обычным символом.

Регистр не учитывается: `подс` и `ПОДС` дают одинаковый результат.

## Чем это отличается от масок в окне «Настройки»

Это разные механизмы, их легко перепутать:

| | поля «Поиск» главного окна | маски в окне «Настройки» |
|---|---|---|
| назначение | временно сузить список на экране | постоянно задать, какие слои и блоки берёт задача |
| разделитель вариантов | запятая `,` | точка с запятой `;` |
| доступны `#` и `@` | да | нет, только `*` и `?` |
| сохраняется в settings.ini | нет | да |

## Взаимодействие с остальным окном

- Поиск СУЖАЕТ результат групповых фильтров («Мои», «Фасады», «Витражи»,
  «Окна»), а не заменяет его: слой вне фильтра поиском не достать.
- Смена запроса сбрасывает выделение слоёв — отбор начинается заново.
- «Выбрать все» и «Снять выделение» действуют на НАЙДЕННЫЕ слои, поэтому
  работает приём «найти по маске -> Выбрать все».
- Поиск не меняет правило «слои не выбраны — задача идёт по всем слоям».
  Это помощник выбора, а не фильтр задачи.
