# Тесты AutoExtraction

Автоматизированное тестирование модулей без AutoCAD (mock-окружение на Python):

- `autolisp.py` — мини-интерпретатор диалекта AutoLISP, достаточный для
  загрузки и выполнения `common/*.lsp` и `Extraction/*.lsp`;
- `acad_mocks.py` — моки AutoCAD: команда/консоль, входной поток, DCL-диалоги,
  entget/entmake-«база» примитивов, vla-/vlax-объекты, виртуальная
  файловая система (CP1251);
- `run_stage5_tests.py` — прогон Этапа 5 (модуль «Заполнение» + регрессия
  диспетчера EXTRACTION). 24 теста в 5 группах;
- `stage5_report.md` — отчёт о прогоне;
- `ЗАПУСК-ТЕСТОВ.md` — инструкция: как запускать прогон и читать результат;
- `РАЗБОР-ДЕФЕКТОВ.md` — подробный разбор найденных дефектов.

Быстрый старт:

```
python3 tests/run_stage5_tests.py
```

Exit-код `0` означает, что все тесты прошли. Подробности — в `ЗАПУСК-ТЕСТОВ.md`.
